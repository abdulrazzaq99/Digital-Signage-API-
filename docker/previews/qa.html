Pretend screen (if you have no real screen)

These two boxes behave like real screens. Nothing to install and nothing to type: just use the buttons.

  1. Click Get a pairing code. A 6-character code appears in the box.
  2. In the portal, open Screens, then Pair Screen, and type that code (test C1).
  3. The box pairs by itself and the portal shows the screen as Online. Whatever you publish to it plays in the box.

Keep this page open in its own tab while you test: the screen is only Online while this page is open. Use the second box for tests that need two screens.

Advanced: do the same with typed commands instead

You do not need these if you use the boxes above. Choose your computer:

How to open it: click the Start button, type PowerShell, press Enter. A blue or black window opens. To paste a command, copy it here, right-click inside that window (or press Ctrl+V), then press Enter.

Keep the same window open for all the steps: it remembers the screen's details, so you do not need to copy or replace anything.

0. Do this once when you open the window 
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
$api = "https://api.addifytv.nu/api/v1/player"
1. Get a pairing code (valid for 5 minutes) 
$s = (Invoke-RestMethod -Method Post -Uri "$api/pairing-sessions" -ContentType "application/json" -Body '{"deviceId":"test-device-001","model":"Test player","playerVersion":"1.0.0"}').data; $s
It shows a code of 6 characters. Use that code in test C1. For a second screen, change test-device-001 to test-device-002.

2. After pairing in the portal, collect the screen's key 
$r = (Invoke-RestMethod -Uri "$api/pairing-sessions/$($s.sessionId)").data; if ($r.credential) { $key = $r.credential }; "Status: $($r.status)"; "Key: $key"
Status: PAIRED with a long key means it worked. PENDING means the screen is not paired yet: finish test C1, then run this again. EXPIRED means the 5 minutes ran out: run step 1 again for a new code.

3. Tell the portal the screen is on (run it again every minute to stay Online) 
Invoke-RestMethod -Method Post -Uri "$api/heartbeat" -Headers @{ Authorization = "Bearer $key" } -ContentType "application/json" -Body '{"state":"PLAYING","resolution":"1920x1080","playerVersion":"1.0.0"}'
4. See what the screen was told to play 
(Invoke-RestMethod -Uri "$api/manifest" -Headers @{ Authorization = "Bearer $key" }).data | ConvertTo-Json -Depth 8
Look for version, items and assets in what it prints.

5. Confirm the screen received it (put the version number from step 4 in place of 1) 
Invoke-RestMethod -Method Post -Uri "$api/sync-ack" -Headers @{ Authorization = "Bearer $key" } -ContentType "application/json" -Body '{"version":1,"status":"activated"}'
This one prints nothing when it works.

If a command shows red text: "401" or "Unauthorized" means there is no key yet, or the screen was unpaired or deleted: start again from step 1. If you closed the window, run step 0 again and start from step 1 (the window forgets everything when closed).

How to open it: press Cmd+Space, type Terminal, press Enter. Paste a command with Cmd+V, then press Enter. Replace the words in CAPITALS with the values you get back.

1. Get a pairing code (valid for 5 minutes) 
curl -s -X POST https://api.addifytv.nu/api/v1/player/pairing-sessions -H 'content-type: application/json' -d '{"deviceId":"test-device-001","model":"Test player","playerVersion":"1.0.0"}'
It prints a sessionId and a 6-character code. Use the code in test C1. For a second screen, change test-device-001 to test-device-002.

2. After pairing in the portal, collect the screen's key 
curl -s https://api.addifytv.nu/api/v1/player/pairing-sessions/SESSION_ID
"status":"PAIRED" comes with a credential. Keep it; it is shown only once. PENDING means not paired yet; EXPIRED means run step 1 again.

3. Tell the portal the screen is on (repeat every minute to stay Online) 
curl -s -X POST https://api.addifytv.nu/api/v1/player/heartbeat -H 'authorization: Bearer CREDENTIAL' -H 'content-type: application/json' -d '{"state":"PLAYING","resolution":"1920x1080","playerVersion":"1.0.0"}'
4. See what the screen was told to play 
curl -s https://api.addifytv.nu/api/v1/player/manifest -H 'authorization: Bearer CREDENTIAL'
5. Confirm the screen received it (use the version number from step 4) 
curl -s -X POST https://api.addifytv.nu/api/v1/player/sync-ack -H 'authorization: Bearer CREDENTIAL' -H 'content-type: application/json' -d '{"version":1,"status":"activated"}'
